내 PC에 앱 다운로드 및 로컬 실행

💡 로컬 파일 실행의 장점:
HTML 파일을 다운로드하여 내 PC에서 열면 브라우저 보안(HTTPS ↔ HTTP 통신 차단) 없이 로컬 Ollama(http://127.0.0.1:11434)와 100% 원활하게 통신합니다.

🚀 초간단 실행 방법 (3단계):

  1. 아래 [HTML 파일 다운로드] 버튼을 누릅니다.
  2. 다운로드된 ollama-say.html 파일을 브라우저(Chrome, Edge, Whale 등)로 더블 클릭하여 실행합니다.
  3. Ollama가 켜져 있으면 자동으로 로컬 모델을 인식하여 즉시 채팅이 시작됩니다!
