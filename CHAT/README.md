# Ollama Say 문서 작업실

`start-ollama-say.bat`를 실행하세요. Python 3와 Ollama가 필요합니다.
브라우저 주소는 `http://127.0.0.1:8767`입니다. 서버 창을 닫으면 연결도 종료됩니다.

- 왼쪽: Markdown 편집 / MD+PV / PV, KaTeX 수식, IndexedDB 자동 저장, 문서 선택, .md 내보내기 및 .md/.txt 불러오기.
- 편집 기록: Ctrl+Z / Ctrl+Y, 저장: Ctrl+S. 답변 삽입은 마지막 선택 영역을 대체하거나 커서 위치에 삽입합니다.
- 답변: MD 복사, 서식 있는 HTML 복사, 별도 창의 MD/PV 및 50~250% 확대·축소.
- 설정: 시스템 프롬프트 자동 저장. 비워두면 모드별 기본 지침, 입력하면 해당 지침을 대체합니다. HTML 앱 다운로드도 설정에 있습니다.
- 문서 목록에서 여러 문서를 만들고 전환할 수 있습니다. 전체 저장은 모든 문서를 IndexedDB에 저장하고 JSON 백업을 다운로드합니다. 전체 복원은 원본을 덮어쓰지 않고 새 ID의 문서로 추가합니다.
- 편집기 코드는 언어별 색상으로 표시됩니다. H1/H2/H3, Bold, 기울기, 목록, 코드, Mermaid, 수식, 표 삽입 버튼은 커서 또는 선택 영역에 적용됩니다.
- 편집기 PV와 답변은 코드 색상, Mermaid, KaTeX를 공통 렌더러로 표시합니다. 답변의 소스 보기 버튼으로 원본 Markdown을 확인할 수 있습니다.
- 추론 모드 옆 추론 보기는 Ollama가 제공하는 message.thinking 스트림을 실시간 표시합니다. 모델이 지원하지 않는 추론을 생성해 보여주지 않습니다. 추론 미지원 모델은 즉시 모드를 사용하세요.
- GitHub 설정: 토큰, owner/repository, 브랜치(빈칸이면 기본 브랜치). 연결 확인은 사용자 인증·저장소·브랜치를 읽기 검증합니다. Fine-grained 토큰에는 해당 저장소의 Contents 읽기/쓰기가 필요합니다.
- GitHub 커밋·푸시는 현재 문서 한 개를 Contents API로 원격 브랜치에 커밋합니다. 파일 경로와 메시지를 확인한 뒤 실행하세요. 기존 파일은 덮어쓰기 확인과 SHA 충돌 검사를 거칩니다. 로컬 git checkout이나 강제 push는 하지 않습니다.
- GitHub 토큰은 현재 창 메모리에만 보관하며 새로고침하면 다시 입력해야 합니다. 저장소·브랜치만 로컬 설정에 저장됩니다. 토큰은 전체 백업 및 앱 다운로드에 포함되지 않습니다.
- 실행 서버는 `ollama list`의 모든 모델을 표시합니다. 임베딩 전용 모델도 목록에 포함되므로 채팅에는 생성 모델을 선택하세요.
- 서버는 127.0.0.1에만 바인딩되며 고정된 Ollama 채팅 API만 중계합니다.

HTML을 직접 열 수도 있지만, 이 경우 모델 목록은 `/api/tags`로 읽으며 Ollama의 CORS 허용 설정이 필요할 수 있습니다.
현재 React, Tailwind, Markdown, KaTeX 라이브러리는 CDN을 사용하므로 **완전 오프라인 앱은 아닙니다**.
문서는 브라우저·주소별 IndexedDB에 저장됩니다. 파일 직접 실행과 로컬 서버의 저장소는 서로 다릅니다.
대화는 별도 IndexedDB(`ollama-say-chats`)에 자동 저장됩니다. 대화 목록, 질문·답변·추론·검색 출처, 선택한 대화와 모드, 입력 초안을 복원합니다. 생성 중에는 약 300ms 간격으로, 완료·중지·대화 삭제 시에는 바로 저장합니다. 새로고침하면 생성 요청 자체는 재개되지 않습니다. 저장 상태는 대화 목록 아래에 표시됩니다. 여러 창을 동시에 사용하면 마지막에 저장한 창의 대화 상태가 남습니다.
대화 저장소도 브라우저·주소별로 구분되며 브라우저 데이터 삭제 시 지워집니다. 문서 전체 백업이나 HTML 앱 다운로드에는 대화가 포함되지 않습니다.
브라우저 데이터 삭제 시 문서도 지워지므로 중요한 문서는 .md로 내보내세요. HTML 앱 다운로드에는 개인 문서가 포함되지 않습니다.
검색/학술검색은 외부 API로 질의를 전송합니다. 학술검색은 OpenAlex, Crossref, arXiv를 각각 조회하며 같은 논문이 여러 데이터베이스에 있더라도 공급자별 결과를 모두 표시합니다. 학술검색 버튼 옆에서 10/120/30/50/100건 또는 1~300건 직접 입력을 선택할 수 있습니다.
모든 모드의 기본 응답에는 `~이다`, `~하였다` 형태의 전문적인 한국어 학술 문체 지침이 적용됩니다. 사용자 시스템 프롬프트를 입력해도 이 기본 문체 지침은 함께 적용됩니다.
